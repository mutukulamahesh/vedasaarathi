# Security policy

VedaSaarathi is a small, free project run by one maintainer (ASCOR LABS).
It has no accounts, no server-side database and no payments; people,
Gotra and location details are stored only in the visitor's own browser.
Security reports are still very welcome.

## Reporting a vulnerability

Please report privately — do not open a public issue for a security problem.

- Preferred: GitHub's **"Report a vulnerability"** button on this
  repository's **Security** tab (private vulnerability reporting).
- Or email **contact.vedasarathi@gmail.com** with "Security" in the subject.

Helpful details: what you found, the page or file involved, steps to
reproduce, and what an attacker could do with it. Please do not include
anyone's real personal or family details in a report.

## What to expect

- An acknowledgement, usually within **7 days**.
- An honest assessment and, for a confirmed problem, a fix or mitigation
  plan. Fix times depend on severity and on one person's availability; there
  is no guaranteed deadline.
- Credit in the fix notes if you would like it.

There is no bug-bounty or paid reward programme.

## Scope and testing

In scope: this repository's code and the site it builds
(https://vedasaarathi.com).

Please test only against your own local build or with light, ordinary use
of the live site. Do not run load tests, denial-of-service tests, automated
scanners at volume, or anything that could affect other visitors, and do
not access data that is not yours.

Hosting-platform behaviour (for example, cookies or bot checks added by the
hosting network) is outside this repository's control; reports about it are
still useful and will be passed on where possible.
