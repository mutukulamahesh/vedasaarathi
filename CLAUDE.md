# VedaSaarathi project guidance

VedaSaarathi should be built as a trustworthy, respectful guide to dharma knowledge and Panchanga data.

## Working agreements

- Read the relevant document in `docs/` before changing a domain or architectural boundary.
- Preserve provenance, uncertainty, and regional or tradition-specific context in sacred content.
- Keep calculations deterministic and testable; do not hide timezone or location assumptions.
- Treat user data and location data as sensitive.
- Follow the rules in `.claude/rules/` for architecture, sacred content, testing, security, and coding.
