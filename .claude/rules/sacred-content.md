# Sacred content rules

NEVER generate or modify canonical mantras.

NEVER invent:
- Gotra
- Pravara
- Veda
- Shakha
- Sutra
- Sampradaya
- ritual procedure
- festival observance rule

Unknown user attributes MUST remain UNKNOWN.

Canonical sacred content must have:
- source
- source location/reference
- tradition
- language/script
- reviewer status
- version

AI-generated explanation must be kept separate
from canonical source content.

If authoritative sources conflict,
preserve the alternatives rather than silently choosing one.
