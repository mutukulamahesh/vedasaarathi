# Testing Rules

- Test the complete beginner journey from home through puja completion.
- Test individual, family, and student/friends group scenarios.
- Test KNOWN, UNKNOWN, and UNSURE independently for each tradition field.
- Assert that unknown lineage information is never inferred or inserted into Sankalpam.
- Assert that canonical mantras cannot be modified by explanation or translation features.
- Test missing materials, partial checklists, saved progress, pause, resume, previous, and next.
- Test location permission granted, denied, unavailable, and manual-location paths.
- Test mobile layouts, keyboard navigation, accessible names, and readable text.
- Treat any unverified religious content displayed as approved as a release-blocking failure.
- Run the build and relevant automated tests before every release.
