# VedaSaarathi Vinayaka Chavithi Pilot

Target: private production pilot by September 8, 2026.

## Product language rule

Every screen must be understandable to a person performing puja for the first time.

- Use short sentences and familiar words.
- Explain every Sanskrit or ritual term immediately.
- Tell the user what to do before explaining why.
- Never use fear, blame, or language suggesting that a sincere beginner has failed.
- Never guess Gotra, Veda, Sutra, lineage, mantra, or ritual rules.
- Clearly label verified sources, priest-reviewed practice, regional custom, and pending review.

## Current implementation

The working application currently includes:

- Personalized home screen
- Location-based Panchanga placeholders that cannot present unverified values
- Vinayaka Chavithi preparation entry point
- Multiple participant forms
- Unknown Gotra protection
- Materials checklist and saved progress
- Plain-language 21-leaf fallback explanation with review status
- Guided puja step engine
- Explanation and audio controls
- Locked states for sacred content awaiting approval
- Completion screen

## Release boundary

The interface and workflow may ship only after technical testing. Mantras, Sankalpam wording, ritual requirements, substitutions, and calendar values require the separate religious-content approval gate.
